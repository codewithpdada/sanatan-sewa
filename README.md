# 🚩 Sanatan Sewa by Pratham Dada

A modern, responsive, and interactive devotional web application dedicated to Sanatan Dharma. The platform features curated devotional bhajans (featuring Lakhbir Singh Lakkha), interactive deity selection, dynamic hero cards with quotes, daily Aarti schedules, and devotional articles.

---

## ✨ Features

* **🔱 Dynamic Deity Selection:** Switch seamlessly between Lord Shiva, Lord Hanuman, Lord Ram, and Durga Maa to instantly update featured imagery, quotes, and playlists.
* **🎵 Lakhbir Singh Lakkha Audio Player:** Integrated audio player with play/pause, track skipping, volume control, and an active visualizer animation.
* **📜 Interactive Playlist:** Real-time track selection and highlight synchronization for devotional bhajans.
* **🔔 Daily Aarti Schedule:** Clean schedule layout displaying timing for morning and evening Aartis.
* **📖 Devotional Articles:** Space for blogs and spiritual literature.
* **🎨 Glassmorphism & Saffron Theme:** Modern UI built with custom CSS variables, gradient accents, and responsive layout grids.
